# 音效和震动反馈使用指南

## 📖 概述

本项目实现了完整的音效和震动反馈系统，为用户提供沉浸式的交互体验。

## 🎵 音效系统

### 音效类型

1. **点击音效** (`click.mp3`)
   - 触发时机：点击主页面卡片
   - 特点：轻快、短促

2. **旋转音效** (`spin.mp3`)
   - 触发时机：开始抽奖（转盘、老虎机、九宫格等）
   - 特点：持续性、有动感

3. **成功音效** (`success.mp3`)
   - 触发时机：显示抽奖结果
   - 特点：欢快、有庆祝感

4. **刮擦音效** (`scratch.mp3`)
   - 触发时机：刮刮乐涂层擦除
   - 特点：摩擦感、短促

### FeedbackService 方法

```dart
// 播放音效
FeedbackService.playClickSound();    // 点击音效
FeedbackService.playSpinSound();     // 旋转音效
FeedbackService.playSuccessSound();  // 成功音效
FeedbackService.playScratchSound();  // 刮擦音效
FeedbackService.stopSound();         // 停止音效
```

## 📳 震动反馈

### 震动强度

1. **轻震动** (50ms)
   - 使用场景：按钮点击、刮刮乐刮擦
   - 方法：`FeedbackService.lightVibrate()`

2. **中等震动** (100ms)
   - 使用场景：开始抽奖
   - 方法：`FeedbackService.mediumVibrate()`

3. **重震动** (200ms)
   - 使用场景：重要操作
   - 方法：`FeedbackService.heavyVibrate()`

### 自定义震动模式

1. **成功震动** (短-停-短-停-长)
   ```dart
   FeedbackService.successVibrate();
   // pattern: [0, 50, 50, 50, 50, 200]
   ```

2. **摇动震动** (连续三次)
   ```dart
   FeedbackService.shakeVibrate();
   // pattern: [0, 100, 50, 100, 50, 100]
   ```

## ⚙️ 配置说明

### 添加音效文件

1. 将音效文件放入 `assets/sounds/` 目录
2. 文件命名规则：
   - `click.mp3` - 点击音效
   - `spin.mp3` - 旋转音效
   - `success.mp3` - 成功音效
   - `scratch.mp3` - 刮擦音效

3. 确保 `pubspec.yaml` 中已配置：
   ```yaml
   flutter:
     assets:
       - assets/sounds/
   ```

### Android 权限配置

震动功能需要在 `android/app/src/main/AndroidManifest.xml` 添加权限：

```xml
<uses-permission android:name="android.permission.VIBRATE"/>
```

### iOS 配置

iOS 设备默认支持震动，无需额外配置。

## 🐛 故障排除

### 音效无法播放

1. **检查文件是否存在**
   - 确认音效文件已放入 `assets/sounds/` 目录
   - 文件名与代码中引用的名称一致

2. **检查文件格式**
   - 推荐使用 MP3 格式
   - 确保文件没有损坏

3. **检查 pubspec.yaml**
   - 确认 assets 路径配置正确
   - 运行 `flutter pub get` 重新加载配置

### 震动无效

1. **检查权限**
   - Android: 确认已添加 VIBRATE 权限
   - 检查设备是否支持震动

2. **检查设备设置**
   - 确认设备未开启静音模式
   - 检查震动设置是否开启

3. **模拟器问题**
   - 某些模拟器不支持震动功能
   - 建议使用真实设备测试

## 💡 最佳实践

1. **音效文件优化**
   - 使用压缩的音频格式
   - 控制文件大小（建议 < 500KB）
   - 采样率不宜过高（44100 Hz 足够）

2. **震动使用建议**
   - 不要过度使用震动
   - 震动强度与操作重要性匹配
   - 考虑用户可能关闭震动的情况

3. **用户体验**
   - 提供关闭音效和震动的选项
   - 尊重系统静音设置
   - 音效和震动应该增强而非干扰体验
